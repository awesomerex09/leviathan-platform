# JerryWeb (Leviathan Signals Dashboard) 🌐

> **Part of the Leviathan Ecosystem**  
> 🔗 [LVIS (Quant Engine)](https://github.com/awesomerex09/LVIS) | 🔗 [Analistics (Data Automation)](https://github.com/awesomerex09/Analistics)

## 📌 Project Overview
JerryWeb is the **full-stack presentation layer** of the Leviathan ecosystem. It is a high-performance, serverless web application designed to deliver real-time quantitative signals, ETF tracking, and market analytics to end users with zero latency. 

Focusing on premium UI/UX aesthetics, the platform integrates seamlessly with backend databases to render dynamic content while maintaining airtight security for proprietary data.

## 🛠 Tech Stack & Core Competencies
- **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Custom design system with dynamic themes and micro-animations).
- **Backend**: Node.js, Vercel Serverless Functions (`api/`).
- **Database/Cache**: Vercel KV (Redis) integration for sub-millisecond state retrieval.
- **Analytics & Delivery**: Cloudflare Web Analytics, API route protection, and dynamic external API proxying (Yahoo Finance integration).

## 🚀 Role in the Ecosystem
1. **Visualization**: Consumes backtest data and live signal states generated by **[LVIS](https://github.com/awesomerex09/LVIS)**.
2. **User Interface**: Provides a sleek, responsive dashboard for users to interact with the quantitative models.
3. **API Gateway**: Acts as a secure intermediary (`/api`) to abstract external financial endpoints and protect internal infrastructure tokens.

## 📁 Repository Highlights
- `api/`: Serverless functions demonstrating secure environment variable usage, Redis KV interaction, and error handling.
- `index.html` & `shared.css`: Modular, token-based design system achieving premium aesthetics without heavy frontend frameworks.
- `.env.example`: Secure blueprint for deploying the serverless architecture.
