# JerryWeb: Full-Stack Web Platform

## Project Overview
JerryWeb is a full-stack data visualization platform that serves real-time quantitative trading metrics and ETF performance data. It integrates backend automated data processing with an interactive frontend to display dynamic portfolios and market insights.

## Tech Stack
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend**: Node.js (Serverless Functions via Vercel)
* **Storage**: Vercel KV (Redis)
* **Deployment**: Vercel

## Architecture / Features
* **Serverless API Endpoints**: Stateless functions (`api/`) to serve JSON data and interact with Key-Value storage securely.
* **Responsive UI/UX**: Built with modern CSS design patterns and asynchronous JavaScript to ensure a seamless, data-rich experience.
* **Automated Data Sync**: Integrates with external data sources and scrapers to keep ETF and pricing data fresh.
